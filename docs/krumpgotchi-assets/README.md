# KrumpGotchi default avatar

**File:** `krumpgotchi-avatar.png`

Default avatar for the KrumpGotchi companion: a cute crustacean with two arms and two legs, wearing a snapback, Timberland-style boots, black jeans, baseball jacket, and circumaural headphones.

**Use in the Lovable app:**
- Copy `krumpgotchi-avatar.png` into your KrumpGotchi project’s public assets (e.g. `public/` or `src/assets/`) and reference it as the default “My KrumpGotchi” image.
- Or host this file (e.g. from the repo or a CDN) and use the URL as the default avatar `src` in the frontend.
