# Exercise media for KrumpGotchi (image + video test)

- **Image:** The default avatar is used for the "image exercise" demo (`../krumpgotchi-avatar.png`). For a real exercise image (e.g. left knee extension), add `left_knee_extension.jpg` (or .png) here and update `exercise-demo.html` to use it.
- **Video:** For the "video exercise" test run, add a short MP4 (e.g. 5–15 seconds) of an exercise demo and name it `sample.mp4` (or update the `<video src>` in `exercise-demo.html` to match your filename). You can use your own clip or a free stock clip (e.g. Pexels).

After adding `sample.mp4`, open `exercise-demo.html` in a browser to run the image + video exercise test.
